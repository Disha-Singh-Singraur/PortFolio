# ⚡ Disha's Neobrutalist Developer Portfolio

Welcome to my developer portfolio! This is a premium, highly interactive web application designed with a bold **Neobrutalist** aesthetic, featuring rich animations, physics-inspired interfaces, and custom interactive canvases.

🔗 **Live Deployment:** [disha-singh-singraur.vercel.app](https://disha-singh-singraur.vercel.app)

---

## 🎨 Design Philosophy & Aesthetics

This portfolio is built around the **Neobrutalist** design trend:
- **Bold Layouts:** Thick, raw black borders (`border-4 border-black`) and flat, offset shadows (`shadow-[8px_8px_0px_0px_rgba(0,0,0,1)]`).
- **High Contrast Palette:** Harmonious mix of highly vibrant, curated HSL colors including Pink, Yellow, Cyan, and Emerald against a warm `#FFFBEF` cream background.
- **Micro-Animations:** Fluid, interactive hover states, swinging cards, and custom cursor trails that make the interface feel alive and interactive.

---

## 🚀 Key Interactive Features

- **🔮 Dynamic Skills Canvas:** A magical skills oracle where skills emerge as floating, colorful orbs. The orbs are connected to a wizard's hand by custom curvy SVG Bézier thread lines. The threads are anchored dynamically using an invisible dummy hand reference system to ensure they are **pixel-perfect across all viewport dimensions** (no alignment shifts on resize or intermediate tablets).
- **🪢 Interactive Rope-Hanging Avatar:** An avatar swinging on a hand-drawn rope that physically sways left or right depending on where you hover your cursor.
- **🖼️ Hanging Projects Gallery:** A physics-inspired gallery where project cards hang on wires with quadratic Bézier curves, reacting with subtle wind sway delays and hover expansion.
- **✨ Fluid Cursor Trail:** A smooth mouse-following trail that guides the user's focus.
- **🥚 Easter Eggs:** Cool mode toggles and hand-drawn navigational paths giving the app a playful, handcrafted feel.

## 💻 Getting Started & Local Development

### 1. Prerequisites
Ensure you have **Node.js** (v18+) and **npm** installed.

### 2. Clone the Repository
```bash
git clone https://github.com/Disha-Singh-Singraur/PortFolio.git
cd PortFolio/my-portfolio
```

### 3. Install Dependencies
```bash
npm install
```

### 5. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### 6. Build for Production
To build the application for deployment:
```bash
npm run build
```
